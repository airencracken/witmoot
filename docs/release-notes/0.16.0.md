# Witmoot 0.16.0

Members have profile pages linked from conversation authors. In Your account,
choose Edit your profile to optionally add a name, a plain-text bio and up to five
labeled HTTP/HTTPS links. Profiles require sign-in, even on a board with public
reading. Your username stays the same; clearing the fields removes them.

Profile pages omit email, private settings and conversation history. Account
exports include your own profile; community exports omit biographies. Suspended
and deleted profiles are unavailable, and account deletion removes profile data.

Comfylib 0.1.5 supplies the shared field validation. Schema 19 adds optional
profile storage without importing any account information into it. Stop the
service and back up the full data directory before upgrading and restarting.
