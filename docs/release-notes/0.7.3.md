# Witmoot 0.7.3

This release includes the OpenRC mail fix and copy refinements from
[0.7.2](0.7.2.md), and fixes an intermittent failure in the demo's test cleanup.
Each test reader now owns and closes its HTTP connection pool before the demo
shuts down. This makes repeated source-package checks reliable.

Application behavior and the database schema are unchanged from 0.7.2. If you
already installed its binaries or Debian packages, this is an optional update.
OpenRC users upgrading from 0.7.1 or earlier should update the service script and
restart Witmoot so its SMTP settings reach the daemon.

See [installation and upgrades](../releases.md) for downloads and checksums.
