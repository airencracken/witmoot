# Witmoot 0.7.3

This release carries the OpenRC mail fix from [0.7.2](0.7.2.md) and fixes an
intermittent failure in the demo's test cleanup.

The app and database are unchanged from 0.7.2, so this update is optional if
you already run it. OpenRC users coming from 0.7.1 or earlier should update the
service script and restart Witmoot so the SMTP settings reach the server.

See [binary releases](../releases.md) for downloads and checksums.
