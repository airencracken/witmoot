# Witmoot 0.19.0

- Create the first owner in the browser with `witmoot setup`. It prints a
  private key, asks for the password twice, and closes once an owner exists.
- `create-owner` and `set-password` work the same across Comfyware: a hidden
  prompt that asks twice, plus `--password-prompt`, `--password-stdin`,
  `--password-file` and `--data-dir`. A password change ends other sessions.
- Older account command names still work.
