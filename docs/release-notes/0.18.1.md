# Witmoot 0.18.1

This patch release adds published Linux amd64 and arm64 images at
`ghcr.io/airencracken/witmoot:v0.18.1`. The images contain the tested native
release binary, CA certificates, timezone data, and zstd for automatic backups.
The Compose example uses private persistent storage, a read-only root
filesystem, a non-root service account, bounded temporary storage, and loopback
port publishing.

See [container installation and operations](../containers.md) for version pins,
first-owner setup, backups, upgrades, and a restore drill. A source checkout can
still build locally using `docker-compose.build.yml`.

There is no new database migration in this patch. Read the
[0.18.0 migration notes](0.18.0.md) when upgrading from an earlier series.
Back up the stopped data volume before upgrading. A downgrade across a schema
change needs the pre-upgrade backup and the matching older binary or image.

The release pipeline tests both architectures on native runners and publishes
only the saved images that passed lifecycle tests. Exact version tags are
preserved; runtime security updates receive a new patch version.
