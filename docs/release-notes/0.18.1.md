# Witmoot 0.18.1

Container images for Linux amd64 and arm64 are now published at
`ghcr.io/airencracken/witmoot:v0.18.1`. They hold the native release binary,
CA certificates, timezone data and zstd. The Compose example uses a private
data volume, a read-only root filesystem, a non-root account and a port
published only on loopback.

See [Run Witmoot with Docker](../containers.md) for version pins, first-owner
setup, backups, upgrades and restores. A source checkout can still build
locally with `docker-compose.build.yml`.

There is no database migration. Coming from before 0.18.0, read its
[migration notes](0.18.0.md). Back up the stopped data volume first. Going
back across a schema change needs the pre-upgrade backup and the matching
older binary or image.
