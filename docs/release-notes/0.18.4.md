# Witmoot 0.18.4

Replying while viewing a message link now refreshes the conversation. Before,
the address could change without loading the new reply, leaving the old
messages and draft on screen.

The reply form also ignores repeat submissions while one is in flight, so a
double press cannot post twice. Replies still work with JavaScript off.

## Upgrade

No database migration; the schema stays at 20. Back up the data directory,
install the new package or image, and restart. Coming from an older schema,
read the [0.18.0 notes](0.18.0.md).
