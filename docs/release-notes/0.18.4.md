# Witmoot 0.18.4

Replies now refresh the conversation when you are already viewing a message
permalink on the same page. Previously the address could change to the saved
reply without loading it, leaving the old messages and draft visible.

The reply form also drops repeated submissions while a request is pending,
in addition to disabling its submit button. This prevents another submit event
from queuing a duplicate reply while the first response is still in flight.

The fix covers consecutive replies, loaded permalinks and conversation page
boundaries. Ordinary navigation with JavaScript disabled continues to work.

## Upgrade

This patch adds no database migrations; the current schema remains 20.
Existing configuration and service paths continue to apply, and Comfylib remains
at v0.1.7. Back up the data directory, install the new package or image, and
restart Witmoot. Read the [0.18.0 notes](0.18.0.md) when upgrading from an older
schema.
