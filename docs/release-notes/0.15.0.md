# Witmoot 0.15.0

Upload your avatar under **Your account → Your avatar**, or copy one from
Imvault. Animated GIFs retain their animation; PNG and JPEG photo uploads and
existing avatars keep working.

- GIFs use Comfylib 0.1.4's shared profile image handling: at most 2 MiB,
  512 by 512 pixels and 64 frames. Metadata is removed and fast frames slowed.
- Each member can disable animated avatars across devices. Device reduced-motion
  preferences and unsigned visitors receive still pictures.
- Personal exports include the still and animated renditions and the member's
  animation preference. Offline pages display the still picture.
- Avatar removal, owner moderation and account deletion remove both renditions.

This release upgrades the database from schema 17 to 18. Stop the service and
back up the entire data directory before upgrading. Normal server startup makes
an automatic pre-migration snapshot. Offline account commands require an explicit
`witmoot migrate` when the database needs an upgrade.
