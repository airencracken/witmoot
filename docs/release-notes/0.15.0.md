# Witmoot 0.15.0

Upload an avatar under **Your account → Your avatar**, or copy one from
Imvault. Animated GIFs keep moving; PNG and JPEG uploads and existing avatars
still work.

- GIFs can be up to 2 MiB, 512 by 512 pixels and 64 frames. Metadata is
  stripped and very fast frames are slowed.
- Each member can turn off animated avatars on every device. Visitors who are
  signed out or prefer reduced motion see still pictures.
- Account exports include both versions and your animation choice.
- Removing an avatar, owner moderation and account deletion remove both
  versions.

The database moves from schema 17 to 18. Stop the service and back up the
whole data directory first. Startup saves a snapshot before migrating. Account
commands need `witmoot migrate` first.
