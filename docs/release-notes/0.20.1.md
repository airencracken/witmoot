# Witmoot 0.20.1

OpenRC and Docker Compose now pass the Apps menu and community sign-in
settings to the server: `WITMOOT_APPS`, `WITMOOT_SHARED_ISSUER`,
`WITMOOT_SHARED_CLIENT_ID`, and `WITMOOT_SHARED_CLIENT_SECRET`. The OpenRC and
systemd settings templates list them, empty by default.

That is the only change from [0.20.0](0.20.0.md). Back up the stopped data
directory before upgrading. There is no new migration.
