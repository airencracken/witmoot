# Witmoot 0.7.2

The OpenRC service now passes every SMTP setting in `/etc/conf.d/witmoot` to
the server. Before, those settings were ignored and email stayed off.

Sign-in buttons use the same label everywhere, and repeated decorative copy
is gone.

Update the service script and restart Witmoot. There are no database
migrations. Keep the configuration file readable only by root (mode 0600).

See [binary releases](../releases.md) for downloads and checksums.
