# Witmoot 0.7.2

The OpenRC service now exports every SMTP setting from `/etc/conf.d/witmoot` to
the server. Previously, the documented plain assignments were ignored and email
delivery stayed disabled.

Sign-in controls now use the same clear label throughout the app. Repeated
decorative copy has been trimmed, and the README describes the existing board
management features instead of calling them future work.

Update the service script and restart Witmoot. Your configuration and data remain
in place; there are no new database migrations. The configuration file should
remain readable only by root (mode 0600).

See [installation and upgrades](../releases.md) for the Linux binaries, Debian
packages, source archive, and checksum manifest.
