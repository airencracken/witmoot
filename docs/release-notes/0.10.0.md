# Witmoot 0.10.0

A hardening release. It fixes defects found in an audit, ties forms to your
session, and moves the sandbox, service configuration, mail and proxy handling
onto Comfylib, the library Witmoot shares with Imvault.

## Before you upgrade

- **Back up the whole stopped data directory.** The database moves from schema
  13 to 14 (the owner activity log). Older releases refuse the newer database,
  so going back means restoring that backup.
- **Mail settings are checked at startup.** With `WITMOOT_SMTP_HOST` set,
  Witmoot needs `WITMOOT_SMTP_FROM` or a `WITMOOT_BASE_URL` with a domain name
  (mail then comes from `no-reply@` that domain). An unknown `WITMOOT_SMTP_TLS`
  value, a malformed sender or an unusable relay host stops startup. Before, an
  unknown TLS mode quietly sent mail in plaintext.
- **Site and board names must fit on one line.** `WITMOOT_NAME`, the site name
  in Settings, and board names and categories refuse line breaks, since the
  site name becomes the subject of reset mail. Existing boards still display;
  fix any multi-line name before saving it again.
- **The sandbox flags `--write-dir` and `--read-file` are gone**, along with
  `WITMOOT_SANDBOX_WRITE_DIR` and `WITMOOT_SANDBOX_READ_FILE`. For a private
  certificate authority, set `SSL_CERT_FILE`; it works inside the sandbox too.
- **The sandbox needs Bubblewrap 0.8 or later**, because the server can no
  longer create user namespaces (`--disable-userns`).
- Pages opened before the upgrade may say "This form has expired" once.
  Reload to fix it.

## Security

- Form tokens are tied to your sign-in, so a cookie planted by another site
  cannot submit forms as you. Every state-changing request is checked, and
  uploads are checked before they are read.
- Taking away a member's invite permission revokes their open invitations.
- Sign-in limits apply per IPv6 /64, survive address floods, and no longer
  count successful sign-ins.
- Reset tokens and unsent mail never appear in logs.
- Mail subjects are encoded, carry a Message-ID, and refuse header injection.
- Key files are written atomically, so a crash cannot leave a short key.

## Fixes

- A rejected mascot or favicon upload no longer blanks the settings form and
  erases the house rules on the next save.
- Uploads get five minutes to arrive; other requests stay tightly limited.
- A failed export stops instead of producing a truncated ZIP, and exports leave
  out names of boards and conversations the member can no longer read.
- Avatars are capped at four megapixels, like branding images.
- `reset-link` and `admin` read `WITMOOT_BASE_URL`, `WITMOOT_NAME` and the mail
  settings from the service configuration, and `admin` only emails complete
  links.
- systemd `EnvironmentFile=` paths may contain spaces.
- OpenRC passes `WITMOOT_SOURCE_URL` to the server.
- The sandbox check no longer needs `/usr/bin/true`, and merged-`/usr` symlinks
  work inside the sandbox.
- Not-found pages name what is missing, and invitation expiry shows "UTC" once.
- The owner activity log links removed messages and records replaced titles
  and avatar removals.
- Repeated member and invitation buttons have per-person accessible names.
- The server logs its version at startup.
