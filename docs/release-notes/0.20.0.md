# Witmoot 0.20.0

- An optional Apps menu, plus consistent keyboard, focus and account controls.
- Optional community sign-in through OpenID Connect. Members link it to their
  existing account; accounts are never created or matched by email address.
  Local passwords keep working.
- Source builds need Go 1.26.11 or newer. golang.org/x/crypto is now v0.59.0.
- The Recent page loads faster, with the same numbering, visibility and links.
- After posting a draft from another app, you can send the conversation link
  back; the source app asks you to confirm before saving it.

See [Comfyware connections](../suite.md). Back up the stopped data directory
before upgrading. Community sign-in adds a table when you configure it. Keep
the pre-upgrade backup for going back to an older binary.
