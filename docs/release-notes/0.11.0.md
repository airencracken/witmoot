# Witmoot 0.11.0

Members can leave, owners can keep a portable community archive, and shared
images make fewer requests to Imvault.

## Before you upgrade

- Stop the server and back up the whole data directory, including
  `imvault.key`. The database moves from schema 14 to 15. Startup also saves a
  database-only snapshot before migrating and stops if that fails. Going back
  to an older binary needs the old database and key.
- Account commands now refuse an outdated schema. Run `witmoot migrate` with
  the service stopped, or let server startup migrate.
- An HTTPS base URL always turns on secure cookies. A loopback listener with no
  trusted proxies logs a warning, because every visitor would share the proxy's
  sign-in rate limit. Set the exact proxy addresses.
- ZIP exports need temporary disk space. Set `TMPDIR` if needed.

## Changes

- **Delete your account** asks for your password and typed username. It clears
  sign-ins, profile, image connection, invitations and access grants. Your
  messages become anonymous placeholders and your conversation titles become
  "Conversation"; other people's replies stay. The last owner must hand over
  first.
- Owners can download a **community archive** from Settings, with private and
  empty boards, conversations, authors, and audience and access rules. It
  leaves out passwords, sessions, email addresses and Imvault keys.
- Member and community archives include available Imvault previews and their
  links, and mark missing ones.
- Deleting a board explains that other members' messages go too, and offers
  the community export and archiving instead.
- Image access checks are cached for 15 seconds, images stream instead of
  buffering, and browsers cache them privately for 15 seconds.
- With JavaScript on, timestamps show in the reader's timezone; UTC is the
  fallback.
