# Witmoot 0.24.0

## Around the board

- **Your account** is grouped into Profile, Times and dates, Sign-in, and Your
  data. **Show animated avatars** is part of the avatar form, and size limits
  appear in the error when a picture breaks them.
- **Settings** starts with the site's name, colors, and mode. Version, metrics,
  and automatic backups moved to a **Server** section at the bottom.
- Owners pick the site's colors under **Settings**: Sage (the default) or
  Slate. Members can choose their own from the theme menu, next to System,
  Light, and Dark. Saved theme choices carry over.
- Board settings show group and individual grants only after you choose
  **Selected members only**.
- The home page drops its site access block; the sidebar explains who can join.
- Invitation and reset links appear once, with a **Copy link** button.
- Sharing a link from another Comfyware app offers a list of recent
  conversations to join, in place of a conversation number.
- Pages say "conversation" and "message" throughout, and "Recent posts" is now
  **Recent messages**.
- Error pages use plain words, and password messages are shorter.
- Downloaded archives use Witmoot's colors and headings.

## Metrics without names

Witmoot no longer records who signs in or what anyone reads. Migration 021
drops the per-member sign-in and per-message and per-image view records that
0.22.0 and 0.23.0 kept. The owner metrics page keeps its counts of members,
boards, conversations, messages, and storage. It adds **Site health**
(requests, errors, response times, and data served per route) and
**Security** (failed sign-ins, rate-limited attempts, and refused invitation
or reset links). None of these name a member, a conversation, or an address.

Migration 022 adds the site color setting.

Take a backup before upgrading. The migrations cannot be undone, and an
older binary refuses the upgraded database; restore the backup to go back.

## For operators

- The binary now listens on `127.0.0.1:8082` when `WITMOOT_ADDR` is not set.
  This affects anyone running `witmoot` without an explicit address, including
  `make run`; set `WITMOOT_ADDR=127.0.0.1:8080` to keep the old port. Packaged
  OpenRC and systemd services already set 8082, and containers set `:8080`
  inside the container, so neither changes.
- `witmoot --help` lists the automatic backup settings.
- Witmoot uses Comfylib 0.7.1: shared site health counts, palettes, theme menu,
  Copy link buttons, error pages, password rule, and size formatting.
