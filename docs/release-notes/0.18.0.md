# Witmoot 0.18.0

## Recent posts

**Recent** shows individual messages, newest first, with their author, board,
conversation, text, images and references. Each links to the exact message.
Pages hold twenty messages with previous and next links. Edits keep their
original place.

Recent follows the usual board, group, member and conversation access rules,
and leaves out removed messages and archived boards.

Migration 020 adds an index on message creation time. It does not rewrite
messages or change their IDs. Startup saves a pre-migration snapshot as usual.
Keep a verified backup before upgrading; going back to an older binary needs
the matching pre-upgrade database.
