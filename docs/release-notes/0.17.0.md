# Witmoot 0.17.0

The running service now makes private, verified, compressed backups on its
own. The first starts one minute after startup, then one every 24 hours. It
uses zstd when installed and gzip otherwise.

It keeps up to seven copies within 10 GiB, and each uncompressed snapshot may
be up to 5 GiB. Old copies are rotated out only after a new one succeeds.
Manual and pre-migration backups are left alone. Owners see the last success,
errors, next attempt and caps in Settings.

See [automatic backups](../automatic-backups.md) for settings and recovery.
There is no database migration. Back up with your current binary before
upgrading; the new worker only protects what comes after.
