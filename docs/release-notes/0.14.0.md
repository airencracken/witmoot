# Witmoot 0.14.0

Talk about music and photo albums from Songstead and Imvault.

Both apps can send a draft to `/share`. Choose a board for a new conversation
or an existing one for a reply, check who can read it, and post as usual.
Opening a draft never posts anything, and each app keeps its own sign-in.

A pasted Songstead recommendation link gets a small reference. An Imvault
album link from your configured server gets one too, and readers can ask for
the album's current public title and image count through the author's Imvault
connection. Private and members-only albums, removed messages, hidden
conversations and disconnected accounts show no preview. Album photos are
never copied into Witmoot.

Keep `WITMOOT_IMVAULT_URL` set to Imvault's canonical address. Songstead needs
no new setting. See [discussion references](../discussion-references.md) and
[the Imvault connection](../imvault.md).

There is no database migration. Back up the whole data directory, including
`imvault.key`, before upgrading.
