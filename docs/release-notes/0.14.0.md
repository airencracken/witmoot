# Witmoot 0.14.0

Explicit discussions about music and photo albums. Uses published Comfylib
v0.1.1 with verified module checksums.

Songstead and imvault can send a browser draft to `/share`. Choose an accessible,
writable board for a dedicated discussion, or an existing topic for a reply.
Review the destination's audience and post through the normal form. Opening a
draft never creates a thread or reply, and each app retains its own sign-in.

Pasting a Songstead recommendation link provides a small source reference.
Configured imvault album links also provide a source reference; readers can
explicitly request the current public album title and image count through the
post author's existing imvault connection. Private or members-only albums,
removed posts, inaccessible topics, disconnected accounts and unavailable
services disclose no preview metadata. Destination links remain usable and
normal discussion reading performs no preview request.

Album contents are not copied into Witmoot. A later privacy change prevents a
new preview request from revealing metadata. No thread is created automatically,
and there is no shared database or required runtime connection.

Keep `WITMOOT_IMVAULT_URL` set to your imvault's canonical public address. Each
member connects their own imvault API key through Settings. Songstead references
require no new environment variable or API key. See
[discussion references](../discussion-references.md) and
[the imvault connection](../imvault.md).

There is no database migration for these discussion features. Stop the old
service and back up the complete data directory, including the existing
imvault encryption key, before upgrading. Standalone builds and release checks resolve the published library with
`GOWORK=off`; no local workspace or replacement is needed.
