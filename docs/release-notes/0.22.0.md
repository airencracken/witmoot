# Witmoot 0.22.0

The metrics page now shares one dashboard design with the other Comfyware
apps. It began recording successful sign-ins and opened conversations and
images per account, without IP addresses or browser identifiers, and showed
owners recent sign-ins and most-viewed content for the past seven UTC days.
Activity was kept for ninety days and removed with its account.

Later versions stopped recording per-member activity; see
[instance metrics](../deployment.md#instance-metrics).

No application migration. Back up before upgrading.
