# Witmoot 0.12.0

Choose a **Display timezone** in **Your account**. UTC is the default for both
existing and new members. Dates and times follow your saved choice on every
device, including daylight saving changes and without JavaScript.

Type an IANA timezone such as `America/Los_Angeles`, or use the city suggestions.
With JavaScript enabled, **Use this device's timezone** fills the field; you
still choose whether to save it. Browsing never changes the preference.

The readable offline archive uses your timezone too. Export manifests retain
UTC timestamps and include the account's timezone preference. Standalone
binaries include fallback timezone data for minimal hosts.

Stop the old server and back up the entire data directory, including
`imvault.key`, before upgrading. The database moves from schema 15 to 16.
Startup saves a database-only snapshot before migrating. Ordinary CLI commands
refuse outdated schemas; use `witmoot migrate` with the service stopped, or let
server startup apply the migration. Older binaries require the corresponding
pre-upgrade database and encryption key.
