# Witmoot 0.12.0

Choose a **Display timezone** in **Your account**. UTC is the default. Dates
and times follow your choice on every device, through daylight saving, with or
without JavaScript.

Type an IANA timezone such as `America/Los_Angeles` or pick a suggested city.
With JavaScript, **Use this device's timezone** fills the field; you still
choose whether to save. The offline archive uses your timezone too; its
manifest keeps UTC timestamps and records your choice. The binary carries its
own timezone data for minimal hosts.

Stop the server and back up the whole data directory, including
`imvault.key`. The database moves from schema 15 to 16, and startup saves a
snapshot first. Account commands refuse the old schema; run `witmoot migrate`
with the service stopped, or let startup migrate. Older binaries need the
pre-upgrade database and key.
