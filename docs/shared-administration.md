# Shared administration helpers

Witmoot uses Comfylib for hidden password prompts and for resizing branding
images, the same code as Songstead and the other Comfyware apps. Prompts hide
your typing and restore the terminal afterward. Branding uploads stay limited
to 2 MiB and 2048 by 2048 pixels and are saved as PNG. Prompt wording and
password rules stay Witmoot's own.
